# UX/UI audit — 2026-05-01

Fresh-eyes audit of Voyage Map, T-8 days from departure. Tested at 1440×900
(desktop) and 390×844 (mobile portrait) against the live `voyage_map.db`
(USA Southwest 2026, 22 itinerary rows / 20 unique dates).

## [P0] Live-mirror snapshot writes throw DataCloneError on every edit

**Where**: `frontend/src/lib/snapshot.js:76` (called from
`frontend/src/views/MapView.vue:476` deep watcher).
**What**: The MapView watcher passes the reactive `mapData.value` Proxy into
`writeSnapshot`. IndexedDB's structured-clone rejects Vue Proxies, so every
mutation logs `DataCloneError`. The intended "live mirror in IndexedDB" is
broken — only the initial `api.getMap` JSON gets persisted; in-app edits
don't reach the snapshot until the next full refetch.
**Fix**: clone-strip `payload` to plain JSON inside `writeSnapshot` before
`store.put`.

## [P1] Recents card "days" miscounts when stops share a date

**Where**: `frontend/src/views/MapView.vue:454-467` (and `:586-588`
inside `adoptMap`).
**What**: Home shows "22 days · 2 trails · 1 pin" for a trip whose itinerary
header (and the `Itinerary.vue` `uniqueDateCount`) reads "20 days". The
recents writer counts itinerary rows; same-date stops (Vegas + Excalibur
Hotel on May 9; Untitled + Cave Spring on May 11) double-count.
**Fix**: count unique `date` values in the recents stats updater, matching
the rest of the app.

## [P2] "forecast in Nd" reads as "from this row", but means "from today"

**Where**: `frontend/src/components/Itinerary.vue:61`.
**What**: For days past Open-Meteo's 16-day horizon the row shows "·
forecast in 5d". Reads ambiguously in a 22-day list — the user has to hover
to see the title attribute clarifying "checks back from {today}".
**Fix**: rephrase to "available 5d before" or "not yet — 5d to go".

## [P2] Tab bar emoji feel like garnish, not signal

**Where**: `frontend/src/views/MapView.vue:250-254` (`tabs` array,
icons 🗓 / 📍 / ⋯).
**What**: Each tab already carries a label; the emoji adds visual noise and
clashes with the vintage palette (color emoji on a cream/ink page).
**Fix**: drop the icons, or replace with monoglyph ASCII chips. (Owner has
explicitly disliked emoji in the past — leave decision to owner.)

## [P2] Itinerary action icons are below 44×44 mobile hit target

**Where**: `frontend/src/components/Itinerary.vue:618-628` (`.iti-icon`).
**What**: Padding `0.25rem 0.35rem` on a 0.9rem glyph yields ~24×26px. On
390-wide viewport, missing by half.
**Fix**: bump padding to `0.45rem 0.55rem` on mobile (`@media`).

## Things checked, no issue found

- Theme toggle (light / dark): contrast OK on both, day-pin halo readable.
- FAB popover: opens, closes on outside-click, hides when armed.
- Day-edit modal: keyboard focus on date, Escape closes, Save submits.
- Mobile sheet: peek (8%) → half (50%) → full (92%) drag works; FAB
  hides via `body.sheet-expanded` when above peek.
- Drop-mode: cursor flips to crosshair via body class.
- Today-banner: dismissible, weather + sunrise/set rendered, edit/×.
- Mobile tab promotion: tapping Trip from peek goes straight to full
  (otherwise itinerary is unreadable).
- Existing `frontend/test/*.test.mjs` (4 files): all pass before changes.
